Do I need an AI account or API key to use UOS?+

No. UOS uses account-free device access—just install, review the one-time consent screen, and click Agree & start. Daily demo usage limits apply.

What files and apps can UOS work with?+

UOS indexes connected folders and can read TXT, Markdown, CSV, JSON, LOG, and ICS files, edit small text files with built-in undo, launch discovered Start-menu apps, and open files in Explorer or their default Windows app.

How does the Chrome companion work?+

The optional Chrome extension pairs locally on 127.0.0.1 with a 256-bit token. You explicitly grant access to individual tabs for 30 minutes—UOS never reads cookies, password fields, or browser history, and you can revoke access in one click.

How does UOS protect my private data?+

Folder access is strictly confined to roots you choose; symlinks escaping those roots, AppData, keychains, and credential files are blocked automatically. Clicking Disconnect stops active work, revokes your device token, and clears local permissions.

Why might Windows SmartScreen flag the installer?+

Release v0.19.11 is an early unsigned development build. Download only from this page and verify its SHA-256 hash against the release record.
