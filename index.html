Good questions.

What do I need to run Utopia?+

Windows 10 or 11, 64-bit, with an internet connection. First-time Setup downloads about 150 MB.

Do I need to connect an AI account?+

No. Open Utopia and agree to get started. Demo usage limits apply.

Can Utopia access everything on my computer?+

No. Only connected folders and shared Chrome tabs. Remove access in Your space; private application data and credential files are excluded.

Which files can it read and edit?+

Read TXT, Markdown, CSV, JSON, LOG, and ICS. Edit small TXT, Markdown, CSV, and JSON files with undo. PDF and Office filenames can be listed, but their contents cannot yet be read.

How do I get new versions?+

Choose Check for updates in the app menu. If Setup fails, download here, quit Utopia from its system tray, and run the installer. Reinstalling starts a fresh UOS session; your files and saved reports are kept.

Why might my browser flag the download?+

This release is not signed with a trusted publisher certificate yet, so browsers and SmartScreen may treat it as an unfamiliar installer. Download only from this page and compare its SHA-256 with the release record. Signing with a trusted publisher certificate is needed to improve reputation warnings.

Is it always working in the background?+

Only while Utopia is running and your computer is awake. It does not control every Windows app.
